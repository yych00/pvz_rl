## 选择规则与解锁时机

Workbench 的 Adventure LIVE 与 Gym Training 卡组面板默认选择 **每关预设卡组**，配置值为 `fixed`。每关有固定的主卡顺序和候选顺序。实际僵尸预览用于提示缺口，不重排固定卡；用户仍可主动切换自动针对或编辑卡组。基础 EnvConfig 的默认值为 `native`，与 GUI 默认不同，详见 [选卡规则与入口](default_adventure_decks.md)。

1. 一周目按本关开始前已获得的植物选择；本关通关奖励从下一关才能使用。即使晚期存档或修改后的游戏显示更多植物，也不把未来奖励混进一周目教学卡组。
2. 先保留游戏不能撤下的戴夫卡，再依次选择主卡；缺卡或尚有空槽时按候选补齐。二周目可使用 40 张基础植物，但不假定升级卡或模仿者的购买状态。
3. 六/八/十槽取固定顺序中实际可选的前六/八/十张。固定指选择规则固定；戴夫锁卡、真实解锁和实际槽位仍决定最终卡组。候选不是随机抽取。
4. 3-1 在十槽环境中只有九张白天可用基础植物，固定加入小喷菇补位；它白天睡觉，不作为有效火力。教程早期如果真实可选卡总数不足槽位，明确报错，不解锁未来植物。
5. 保龄球、打僵尸、砸罐子、传送带和僵王关依赖游戏预置/发牌。以下表中的配置用于记录教学用途；无交互选卡界面就跳过，不能理解为实际可自由挑十张卡。
6. 白天磁力菇的固定选择要求咖啡豆先入组。戴夫锁入的睡眠蘑菇不会被删除，缺唤醒卡时会提示应对缺口。高坚果、火炬、保护伞等仍需要战斗策略正确布置。

关键时机：3-3 用三线射手、水路前排与应急处理潜水，到 3-4 才有海草；3-6 先用辣椒/窝瓜处理冰车，到 3-7 才有地刺；3-8 海豚先靠海草与诱跳，到 3-9 才有高坚果；4-3 用仙人掌处理气球，4-4 才有三叶草；4-6 用裂荚处理矿工，4-9 才有磁力菇；5-1 靠初始花盆，5-2 才能选花盆种子；5-6 投石车先靠爆发，5-7 才有保护伞。

| 植物 | 首次可用关卡 | 教学用途、依赖和限制 |
| --- | --- | --- |
| 豌豆射手 | 1-1 | 基础直线输出；屋顶斜坡前不宜作为主攻。 |
| 向日葵 | 1-2 | 先建立经济；夜间可用阳光菇替代，戴夫给向日葵则保留。 |
| 樱桃炸弹 | 1-3 | 局部范围爆发，处理重甲/集群；给应急留阳光。 |
| 坚果 | 1-4 | 保护输出并争取时间；挡不住撑杆/海豚/跳跳的首次跳跃。 |
| 土豆雷 | 1-6 | 廉价前期击杀，但需要埋设时间；不能当作撑杆必杀。 |
| 寒冰射手 | 1-7 | 一路一株减速，搭配其他输出；与火炬同一路会改变冰豌豆效果。 |
| 大嘴花 | 1-8 | 快速吃掉铁桶等单体；消化期间需要坚果保护。 |
| 双发射手 | 1-9 | 提高持续火力，较贵；前期仍靠地雷/窝瓜稳经济。 |
| 小喷菇 | 2-1 | 夜间免费开局，射程短；白天无咖啡豆只作补位。 |
| 阳光菇 | 2-2 | 夜间便宜经济；成长前单次产量较小。 |
| 大喷菇 | 2-3 | 范围穿透铁门护盾；白天需要咖啡豆。 |
| 墓碑吞噬者 | 2-4 | 清墓扩大布阵空间，减少最终波从墓中出现的压力。 |
| 魅惑菇 | 2-6 | 让吃到它的僵尸反打；橄榄球可转化成友军火力。 |
| 胆小菇 | 2-7 | 廉价远射，近敌会躲；需要前排缓冲。 |
| 寒冰菇 | 2-8 | 全场冻结，处理舞王集群、巨人和紧急节奏；白天需咖啡豆。 |
| 毁灭菇 | 2-9 | 大范围爆发但留下坑；别炸掉关键经济/载具布阵位置。 |
| 睡莲 | 3-1 | 泳池陆生植物的载具；选了载具还要有可放其上的输出。 |
| 窝瓜 | 3-2 | 早期单体应急，也能击杀冰车；巨人需要另一张爆发配合。 |
| 三线射手 | 3-3 | 覆盖相邻三路，陆路对水路提供火力；选位置比堆数量更重要。 |
| 缠绕海草 | 3-4 | 水路单体击杀，对潜水/海豚有效；不能用于陆路。 |
| 火爆辣椒 | 3-6 | 整行爆发并清冰道；屋顶投石车、巨人也可用作救场。 |
| 地刺 | 3-7 | 陆路地面伤害并破轮胎；不作为屋顶/水路的冰车方案。 |
| 火炬树桩 | 3-8 | 增强豌豆输出，须配射手；不独立提供伤害。 |
| 高坚果 | 3-9 | 阻挡撑杆、海豚和跳跳；扶梯仍可让僵尸翻越。 |
| 海蘑菇 | 4-1 | 免费水路近程输出；夜间有效，白天会睡觉。 |
| 路灯花 | 4-2 | 固定照明关键区域；不直接处理气球。 |
| 仙人掌 | 4-3 | 能打气球；4-3 首次气球时的已解锁解法。 |
| 三叶草 | 4-4 | 驱走气球并暂时吹散雾，常能替代仙人掌/路灯的部分槽位。 |
| 裂荚射手 | 4-6 | 向前及向后射击；4-6 首次矿工时的已解锁解法。 |
| 杨桃 | 4-7 | 多个方向覆盖，可处理后排威胁；需要正确位置，非单向主力替代。 |
| 南瓜头 | 4-8 | 保护同格植物，不额外占种植格；注意小鬼落点和高坚果保护。 |
| 磁力菇 | 4-9 | 吸走可吸附金属，如铁桶、门、工具、跳杆、梯子；白天需咖啡豆。 |
| 卷心菜投手 | 5-1 | 投射跨屋顶斜坡；5-1 使用游戏给定初始花盆。 |
| 花盆 | 5-2 | 屋顶扩建载具；5-1 通关后才获得种子卡。 |
| 玉米投手 | 5-3 | 投射输出，黄油可提供短时控制；不能保证每发都控住敌人。 |
| 咖啡豆 | 5-4 | 白天唤醒蘑菇，是白天磁力菇/大喷菇/寒冰菇的依赖。 |
| 大蒜 | 5-6 | 引导能啃食它的步行僵尸改道；不能替代投石车/巨人专门应对。 |
| 叶子保护伞 | 5-7 | 保护附近植物免受蹦极和投石；按覆盖范围布置，单株不保全场。 |
| 金盏花 | 5-8 | 产金币，几乎不贡献战斗能力；固定教学中只作后位候选/补位。 |
| 西瓜投手 | 5-9 | 强范围投射输出，适合最后常规屋顶关；昂贵，仍需前期经济/应急。 |

## 验证范围与来源

这是项目的教学选卡设计，选卡顺序与候选可在 [python/pvz_gym/adventure_curriculum.py](../python/pvz_gym/adventure_curriculum.py) 修改。通过 `python -m scripts.export_adventure_curriculum` 同步此文档。卡组配置覆盖 50 关 × 2 周目；覆盖配置不代表脚本已通关所有关卡。

解锁顺序核对 [LawnApp::GetAwardSeedForLevel / GetSeedsAvailable](https://github.com/Patoke/re-plants-vs-zombies/blob/main/LawnApp.cpp)。新僵尸时机核对 [gZombieDefs](https://github.com/Patoke/re-plants-vs-zombies/blob/main/Lawn/Zombie.cpp)。每关可出僵尸仍受 [Board::CanZombieSpawnOnLevel](https://github.com/Patoke/re-plants-vs-zombies/blob/main/Lawn/Board.cpp) 限制；不能把‘此前已经介绍过’理解为该关必然出现。

运行时以原生 `SeedTypeAvailable`、实际选卡状态、动作掩码和戴夫锁卡为准。单元测试覆盖逐关可用卡与候选、六/八/十槽、固定卡不随预览变化、戴夫锁卡和同局训练衔接。
